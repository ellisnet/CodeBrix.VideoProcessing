clip-h264-aac.mp4
    A SYNTHETIC clip: no camera footage, no recording, no third-party content.
    Picture: ffmpeg's built-in "testsrc2" pattern generator. Sound: ffmpeg's
    built-in "sine" generator (a 440 Hz tone). Licence: none needed - generated
    for this repository and dedicated to the public domain (CC0-1.0) by its
    author.
    Content: 4 s, 320x240, 30 fps (120 frames), H.264 High 4:2:0 8-bit, a
    keyframe every 30 frames (at 0, 1, 2 and 3 s), 2 B-frames; AAC-LC stereo
    48 kHz 96 kbit/s; moov before mdat; no metadata tags.
    Made with the Debian ffmpeg (7.1) of the development laptop:

    ffmpeg -f lavfi -i testsrc2=size=320x240:rate=30:duration=4 \
           -f lavfi -i sine=frequency=440:sample_rate=48000:duration=4 \
           -c:v libx264 -profile:v high -pix_fmt yuv420p -g 30 -keyint_min 30 \
           -sc_threshold 0 -bf 2 -crf 23 \
           -c:a aac -b:a 96k -ac 2 \
           -map_metadata -1 -fflags +bitexact -flags:v +bitexact \
           -flags:a +bitexact -movflags +faststart clip-h264-aac.mp4

    Used by: samples/VideoProcessingDiagnostics (bundled as an Android asset;
    the device proof's input) and tests/CodeBrix.VideoProcessing.Android.Tests
    (the MP4 timing reader's known-answer test).

clip-hevc10-aac.mp4
    A SYNTHETIC clip: no camera footage, no recording, no third-party content.
    Picture: ffmpeg's built-in "color" source turned into a 10-bit luma RAMP
    by the "geq" filter. Sound: ffmpeg's built-in "sine" generator (a 440 Hz
    tone). Licence: none needed - generated for this repository and dedicated
    to the public domain (CC0-1.0) by its author.
    Content: 3 s, 320x180, 30 fps (90 identical frames), HEVC Main 10,
    yuv420p10le, LOSSLESS (x265 lossless=1), a keyframe every 30 frames, no
    B-frames; AAC-LC stereo 48 kHz 96 kbit/s; moov before mdat; no metadata
    tags. The luma is three 60-row bands; in band b (rows 60b..60b+59) the
    sample at column x is 64 + 320b + x, so the frame holds 960 DISTINCT 10-bit
    levels (64..1023) and adjacent columns differ by one 10-bit level - an
    8-bit cut can resolve at most 240 of them. Cb = Cr = 512.
    Made with the Debian ffmpeg (7.1) of the development laptop:

    ffmpeg -f lavfi -i "color=c=black:size=320x180:rate=30:duration=3,format=yuv420p10le,geq=lum='64+floor(Y/60)*320+X':cb=512:cr=512" \
           -f lavfi -i sine=frequency=440:sample_rate=48000:duration=3 \
           -c:v libx265 -profile:v main10 -pix_fmt yuv420p10le \
           -x265-params "lossless=1:keyint=30:min-keyint=30:scenecut=0:bframes=0:log-level=error" \
           -tag:v hvc1 -c:a aac -b:a 96k -ac 2 \
           -map_metadata -1 -fflags +bitexact -flags:v +bitexact \
           -flags:a +bitexact -movflags +faststart clip-hevc10-aac.mp4

    Used by: samples/VideoProcessingDiagnostics (bundled as an Android asset;
    the 10-bit steps 20-21) and tests/CodeBrix.VideoProcessing.Android.Tests
    (the P010 reader is checked bit-exact against the host ffmpeg's decode of
    its first frame).

clip-h264-aac-srt.mp4
    A SYNTHETIC clip: no camera footage, no recording, no third-party content.
    Picture: ffmpeg's built-in "testsrc2" pattern generator. Sound: ffmpeg's
    built-in "sine" generator (a 440 Hz tone). Subtitles: two cues typed for
    this repository ("First caption" 0-1 s, "Second caption" 1-2 s). Licence:
    none needed - generated for this repository and dedicated to the public
    domain (CC0-1.0) by its author.
    Content: 2 s, 320x240, 30 fps (60 frames), H.264 High 4:2:0 8-bit, a
    keyframe every 30 frames, 2 B-frames; AAC-LC stereo 48 kHz 96 kbit/s; ONE
    3GPP timed-text (mov_text) subtitle track, language "eng"; no chapters;
    moov before mdat; no container metadata tags.
    Made with the Debian ffmpeg (7.1) of the development laptop, from a cues.srt
    holding exactly:

        1
        00:00:00,000 --> 00:00:01,000
        First caption

        2
        00:00:01,000 --> 00:00:02,000
        Second caption

    ffmpeg -f lavfi -i testsrc2=size=320x240:rate=30:duration=2 \
           -f lavfi -i sine=frequency=440:sample_rate=48000:duration=2 \
           -i cues.srt -map 0:v -map 1:a -map 2:s \
           -c:v libx264 -profile:v high -pix_fmt yuv420p -g 30 -keyint_min 30 \
           -sc_threshold 0 -bf 2 -crf 23 \
           -c:a aac -b:a 96k -ac 2 \
           -c:s mov_text -metadata:s:s:0 language=eng \
           -map_metadata -1 -map_chapters -1 -fflags +bitexact -flags:v +bitexact \
           -flags:a +bitexact -movflags +faststart clip-h264-aac-srt.mp4

    Used by: samples/VideoProcessingDiagnostics (bundled as an Android asset;
    the subtitle-survey step: Analyse must report one subtitle stream) and
    tests/CodeBrix.VideoProcessing.Tests (the ffmpeg engine's Analyse reports
    the same track).
